Cómo publicar este Hub en GitHub Pages (Paso a Paso)

1. Crear repositorio en GitHub

Crea un repositorio en tu cuenta de GitHub (ej. repositorio-seguros).

2. Subir estos archivos

Sube todos los archivos (index.html, app.js, knowledge_base.json, etc.) a la rama main de tu repositorio.

3. Activar GitHub Pages

Ve a Settings > Pages en GitHub, selecciona la fuente Deploy from a branch, rama main y carpeta / (root).

4. Compartir el enlace con los líderes

Tu web estará disponible en https://tu-usuario.github.io/repositorio-seguros/ lista para ser usada en cualquier navegador.
